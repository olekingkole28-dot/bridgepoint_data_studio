## Main announcement — LinkedIn / Facebook / Bluesky

I started building BridgePoint Intelligence from the ground up. Today, I’m opening the
source code so developers can inspect it, learn from it, fork it, and help improve it.

BridgePoint is an attempt to connect the real world to source-backed property and claims
intelligence: geospatial maps and 3D surfaces, property identity and matching, weather and
event context, provenance-aware evidence, claims-lifecycle data, public utilities, backend
functions, database migrations, automation, and the Flutter application.

This is a working software project—not a claim that every source is available everywhere
or that a map signal proves damage. The repository documents what is included, what depends
on external services, and where data/licence limits apply.

Explore the live experience: https://bridgepointintelligence.online/

Read the code and join the work:
https://github.com/olekingkole28-dot/bridgepoint-live
https://github.com/olekingkole28-dot/bridgepoint_data_studio

I’d especially value issue reports, reproducible bug fixes, geospatial/data-provenance
feedback, performance improvements, and contributions from developers who want to build
open real-world intelligence tools.
